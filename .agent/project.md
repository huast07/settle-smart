The newcomer-agent project is an ADK 2.0 graph-workflow agent that helps newcomers identify local loyalty, rewards, discount, and essential-service programs based on their origin, destination, age, and household profile, while protecting sensitive personal data and routing risky prompt-injection attempts to human review. The goal of an agent working to develop it is to keep evolving that workflow into a reliable, secure, skill-driven support system: one that progressively gathers only necessary user context, sanitizes inputs before model use, applies runtime skills for customization, local program discovery, and recommendations, and produces practical, evidence-aware signup guidance without exposing private information or bypassing safety controls.
