# Newcomer Observability Contract

Load this reference when editing runtime setup, telemetry, feedback logging, or compliance-review metadata.

## Runtime Files

- `app/agent_runtime_app.py`: wraps the ADK app for Agent Runtime and local tests.
- `app/app_utils/telemetry.py`: configures telemetry and prompt-response capture behavior.
- `submission_frontend/main.py`: extracts events, redactions, interruption messages, errors, and event counts for dashboard compliance review.

## Local Test Runtime

When `INTEGRATION_TEST=TRUE`, runtime setup should use in-memory services:

- `InMemoryArtifactService`
- `InMemoryMemoryService`
- `InMemorySessionService`
- local `Runner`
- local feedback logger

This keeps tests independent from live Vertex AI, GCS, Cloud Logging, and Agent Runtime credentials.

## Telemetry Rules

- `GOOGLE_CLOUD_AGENT_ENGINE_ENABLE_TELEMETRY` may be enabled for operational metadata.
- Prompt-response content capture should stay disabled or metadata-only.
- If `LOGS_BUCKET_NAME` is set and content capture is requested, force `OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT=NO_CONTENT`.
- Use resource attributes such as service namespace and commit SHA; do not add raw prompt text or user identity data.

## Feedback Logging

Feedback may include:

- numeric score
- feedback text
- user/session identifiers generated by the app or runtime
- high-level operational context

Feedback should not include raw sensitive identity fields, full prompt transcripts, hidden policies, system rules, or unredacted documents.

## Dashboard Compliance Data

The dashboard compliance review should surface:

- status
- generated timestamp
- informational disclaimer
- redaction categories
- event count
- interruption messages
- backend error detail when applicable

Keep compliance review useful for case managers without exposing protected values.
