Use this skill when developing local program discovery for the Newcomer webapp.

Trigger this skill for requests involving search query generation, Google Search tooling, filesystem runtime search skills, official-source verification, eligibility lookup, signup-path extraction, source confidence, local loyalty programs, rewards programs, discount programs, public benefit pages, grocery chains, transit agencies, banks, credit cards, pharmacies, healthcare, housing or utility programs, telecom carriers, internet affordability programs, and household-specific programs.

The goal is to help the ADK workflow discover real local programs for a newcomer's destination and prioritized essential categories, without inventing program details or overreaching into legal, medical, or financial advice.

When using this skill:

1. Search category by category so food, transit, banking, healthcare/pharmacy, housing/utilities, telecom, and household needs remain balanced.
2. Prefer official provider, government, transit agency, retailer, grocery, pharmacy, bank, credit issuer, utility, telecom, and internet-provider pages over aggregators.
3. Capture eligibility limits, fees, credit checks, service-area constraints, documentation language, signup paths, and confidence.
4. Clearly distinguish commercial loyalty/rewards programs from public benefits or affordability programs.
5. Feed recommendation nodes enough verified candidates to choose up to three credible programs per priority category.

Load `references/search-source-rules.md` when changing search prompts, source-quality behavior, eligibility extraction, signup extraction, or category-specific search rules.
